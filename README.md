# EduShelf

EduShelf - это простой сайт для удаленной загрузки и скачивания учебных материалов. Преподаватели могут добавлять файлы, а студенты - искать и скачивать их через браузер.

## Что реализовано

- обложка с логотипом, приветствием и описанием платформы;
- поиск по ключевым словам в названии, описании и тегах;
- загрузка файлов с указанием названия, описания и ключевых слов;
- скачивание материалов из результатов поиска;
- базовая поддержка форматов: PDF, DOC, DOCX, PPT, PPTX, XLS, XLSX, TXT, ZIP.

## Стек

- Python
- Flask
- HTML / CSS / JavaScript

## Запуск локально

1. Создайте виртуальное окружение:
   `python -m venv .venv`
2. Активируйте его:
   Windows: `.venv\\Scripts\\activate`
3. Установите зависимости:
   `pip install -r requirements.txt`
4. Запустите приложение:
   `python app.py`

После запуска сайт будет доступен по адресу `http://127.0.0.1:5000`.

## Как разместить удаленно

Подойдут сервисы `Render`, `Railway` или `PythonAnywhere`.

### Вариант с Render

1. Загрузите проект в GitHub.
2. Создайте новый `Web Service` в Render.
3. Подключите репозиторий.
4. Укажите:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
5. После деплоя Render выдаст публичный URL, и сайт будет работать удаленно, не на вашем компьютере.

## Хранение данных

Сейчас файлы хранятся в папке `uploads/`, а метаданные материалов - в базе SQLite `data/materials.db`.
Для учебного или стартового проекта этого достаточно, но для полноценной платформы лучше перенести:

- файлы в облачное хранилище, например AWS S3 или Cloudinary;
- метаданные в базу данных, например PostgreSQL.

## Структура проекта

- `app.py` - сервер и API;
- `templates/index.html` - HTML-страница;
- `static/styles.css` - стили;
- `static/app.js` - логика поиска и загрузки;
- `uploads/` - загруженные файлы;
- `data/materials.db` - база SQLite со списком материалов.
